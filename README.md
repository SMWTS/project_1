# Анализ финансовых данных и веб-отображение

Этот проект предназначен для обработки, анализа и визуализации финансовых данных, а также включает тесты для проверки корректности работы функций.

---

## Описание

Проект реализует следующие основные функции:

- Загрузка и обработка данных из CSV-файлов
- Парсинг дат в нужном формате
- Расчет различных метрик и агрегатов (например, расходы по категориям, курсы валют, индекс S&P 500)
- Веб-интерфейс для отображения информации (используя Flask или другой фреймворк)
- Тестирование функций с помощью `unittest` и `pytest`

---

## Основные функции

### Обработка данных

- `parse_dates(df)`: преобразует столбец `'Дата операции'` в формат datetime с учетом формата даты.
- `load_transactions(file_path)`: загружает транзакции из CSV файла.
- `expenses_by_category(df)`: рассчитывает расходы по категориям.
- `load_currency_rates()`: загружает курсы валют.
- `get_sp500_price(date)`: получает цену индекса S&P 500 на указанную дату.

### Веб-интерфейс

- `main_page_handler()`: основной обработчик страницы, собирает данные и передает их в шаблон для отображения.

### Тесты

- Используются тестовые случаи для проверки корректности работы функций:
  - Мокирование внешних вызовов (`load_transactions`, `get_greeting`, `load_currency_rates`, `get_sp500_price`, `expenses_by_category`)
  - Проверка обработки данных и расчетов
  - Проверка веб-обработчика (`main_page_handler`) с помощью моков

## Установка и запуск

Клонируйте репозиторий:

```
git clone https://github.com/SMWTS/project_1.git
```
Создайте виртуальное окружение и активируйте его:

```
python -m venv venv
# Linux/Mac
source venv/bin/activate
# Windows
venv\Scripts\activate
```

Установите зависимости:
```
pip install -r requirements.txt
```
